# FreecamESP (Fabric 1.21.11)

Клиентский мод: Freecam (G) + ESP подсветка сундуков/шалкеров/баррелей/предметов (H).

## Сборка
1. Установи JDK 21.
2. Создай проект из шаблона или положи эти файлы в папку мода.
3. Выполни: `gradlew build` (первый раз скачает зависимости).
4. Готовый jar: `build/libs/freecam-esp-1.0.0.jar`

## Установка
1. Поставь Fabric Loader 1.21.11 (https://fabricmc.net/use/installer).
2. Скачай Fabric API 1.21.11 с Modrinth.
3. Помести jar мода и Fabric API в папку `.minecraft/mods`.

## Важно
- Мод полностью клиентский: freecam и ESP не отправляют пакеты на сервер.
- Риск бана за читы на сервере (FunTime) остается - используй на свой страх и риск.
- Клавиши: G - freecam, H - ESP.
